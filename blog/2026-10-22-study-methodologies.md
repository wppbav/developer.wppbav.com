Study methodologies have new names and descriptions: BAV 1, BAV 1 (Known Brands), Triads V1 and V2, and the BAV 3
variants.

<!-- truncate -->

The studies endpoint now supports `include=methodology` to return each study's methodology with its name and
description, and the `get-markets` MCP tool names the methodology of each study. The underlying keys are unchanged, so
existing integrations keep working.

See [Studies](/docs/2.x/studies) for the full list of methodologies.

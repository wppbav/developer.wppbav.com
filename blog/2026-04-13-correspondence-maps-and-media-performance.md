Two new capabilities have arrived on the BAV MCP server: correspondence maps and media performance benchmarks.

<!-- truncate -->

## Correspondence maps

The new `get-correspondence-map-data` tool runs a correspondence analysis over imagery attributes and returns the
coordinates of brands and attributes on a shared map. It's the same analysis that powers the Correspondence Map in the
platform, and is great for finding whitespace, ownership of attributes and clusters of similar brands.

## Media performance

For brands that use media performance benchmarking, a new set of tools gives agents access to campaign performance
data and benchmarks, such as `get-campaign-performance-data` and `get-campaign-performance-benchmarks`. Access is
granted per brand, so the tools only appear for users who have access to at least one brand.

See the [BAV MCP Server](/docs/2.x/ai/mcp/bav) documentation for details.

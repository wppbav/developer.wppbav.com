# BAV Agents

BAV Agents are specialized AI agents that help users with different tasks. They use advanced natural language
processing. These agents can understand user queries, give relevant information, and do actions from user instructions.

## WPP Open & Creative Studio

Our set of pre-made BAV agents is available in WPP Open and the Agent Hub. You can run these agents standalone. You can
also combine them into more complex workflows, and with other data sources, to make powerful AI-driven analysis.

Our core agent, the Brand Analytics Agent, is a free chat agent. Users can use it to ask about the BAV dataset in
natural language. Users can ask about brand performance, consumer insights, and market trends. The agent gives detailed
responses from the BAV data.

We also have a range of specialized agents for specific parts of brand analysis. These agents can help users with tasks
such as competitive analysis, consumer sentiment analysis, and market segmentation.

To get access to these agents, [contact us](mailto:bavsupport@wpp.com).

## Building your own agents

If you want to build your own agents, you can connect them directly to BAV data with our
[MCP servers](mcp/intro.md). In WPP Open, the MCP servers are available as tools in the Creative Studio agent builder.
Refer to [connecting clients](mcp/connecting-clients.md#wpp-open).
